# 画廊 v0.13.0 · 照片墙大改版：筛选、密度、时间序，归档与地图更省心

> 把旅行照片，做成一本翻不腻的手账。本地优先 · 免安装即用 · 照片原地不动。

这一版围绕「**看照片、挑照片、归类照片**」把首页照片墙和旅行页照片墙全面升级：可以按旅行筛选、三档密度一屏看更多、按拍摄时间排序浏览；同时补齐了两类常见导入场景——**根目录平铺的照片**引导归档、**空目录**自动建成待整理的旅行；地图换用国内可直连的卫星影像源，首次导入大批量照片也不再卡死窗口。

## ✨ 新亮点

- 🧹 **根目录平铺照片自动归档** — 注册相册时若根目录直接放着照片，会弹出确认：一键创建默认旅行并把照片移进对应文件夹（可改旅行名）；取消则不导入、不移动任何文件。归档失败自动回滚，绝不留半成品
- 📁 **空子目录建旅行** — 「先建目录骨架、后补照片」的习惯现在被完整支持：扫描时空子目录也会创建旅行（0 张照片），时间线里以拍立得空白相框占位，随时编辑或删除
- 🗺 **地图国内直连** — 瓦片源换为 Esri 卫星影像（免 Key、国内网络实测稳定加载）+ OSM 回退，多源失败自动切换；照片标记与 EXIF 坐标同系（WGS-84），落点无偏移
- 🔀 **排列方式切换** — 照片墙新增「按时间 / 填充」两种排布：时间序为行优先网格，阅读顺序与时间线一致，旅行页照片改按**拍摄时间**排序（此前是文件名/导入序），灯箱翻页同步跟随；偏好跨启动记忆
- 📐 **密度三档** — 照片墙「大 / 中 / 小」密度随意切：最小档 1080p 一屏约 42 张，批量挑拣归类效率倍增；切换即时生效、全局记忆
- 🎯 **按旅行筛选** — 首页照片墙新增可折叠筛选树：选中某次旅行只看它的照片，计数同步「X / Y」，与收藏/标签/年份筛选叠加
- 🖱 **多选反馈强化** — 选中卡片改为全周均匀的 3px 主题色描边 + 柔和遮罩，勾选徽标改高对比不透明底（选中为绿色粗白勾），过曝/深色照片上一眼可辨；五套主题明暗全部适配
- ⚡ **大批量导入不再卡死** — 缩略图未生成完的照片以占位块显示、绝不回退加载原图（此前首扫期间打开照片墙可能把 Windows 窗口打到「未响应」）；缩略图边生成边点亮，无需刷新
- 🚀 **缩略图生成提速** — 图片与视频分池并行（慢视频不再拖住图片）、并发按 CPU 自适应有界、数据库事务批量落盘；3000 张实测总耗时缩短约 11%，中途退出重启自动续跑

## 🛠 修复与体验优化

- **首次扫描不再无响应（Windows）**：未就绪缩略图统一占位化，原图只在灯箱单张查看时加载——根除了「照片墙批量加载原图 + HEIC 实时转码」把渲染与主进程同时打满的死结
- **滚动回弹消失**：照片卡固定宽高比占位，懒加载完成不再触发瀑布流重平衡；单次勾选只重渲染对应卡片（实测 1/420），滚动中位帧间隔 16.7ms（≈60fps）
- **旅行页照片墙增量渲染**：千张级旅行首屏渲染 500 张、触底追加，不再一次性挂载全部 DOM
- **空旅行/未填日期不再显示「? 天旅程」**：结束日期缺省按当天计，起止缺一不显示天数
- **修复旅行页加载态白屏**：旅行数据未就绪时组件提前返回后的 hook 会触发 React #310 崩溃，已将排序改为纯计算规避
- 时间线卡片、灯箱胶片条、标签/图注/移动弹层的缩略图占位统一，弱网/首扫体验一致
