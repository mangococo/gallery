# 画廊 v0.14.0 · 旅行日期自动重算、应用内检查更新与微信照片修复

> 把旅行照片，做成一本翻不腻的手账。本地优先 · 免安装即用 · 照片原地不动。

这一版补上了两块「用久了才会遇见」的体验：照片搬来搬去之后**旅行日期自动跟着走**，以及不用再手动到 GitHub 看有没有新版——**设置里一键检查更新**。同时修复了一个高频痛点：**微信转存的 HEIC 照片**（文件名是 .jpg、内容其实是 HEIC）此前无法生成缩略图，现在按文件内容智能分流解码。

## ✨ 新亮点

- 📅 **旅行日期自动重算** — 照片迁入、迁出（移动到旅行、导入、删除进回收站、恢复、外部增删文件）时，所属旅行的开始/结束日期按照片拍摄时间自动重算：日期跟着照片走，无需手改。你手动改过的日期**永不被覆盖**——只有「应用自动填的」或「你主动清空的」才会跟随照片变化，随时手改一次即锁定
- 🔍 **应用内检查更新** — 设置新增「关于」区：显示当前版本，一键检查 GitHub 上的最新发布；有新版会展示版本号、发布说明摘要，并一键前往下载页。仅在你点击时联网，不轮询、不自动下载，网络失败给出可读的提示
- 🧩 **微信 HEIC 照片修复** — 微信等 IM 转存的照片常见「HEIC 内容挂着 .jpg 扩展名」，此前缩略图与大图都会显示失败；现在按文件头内容嗅探真实格式、自动分流到兼容解码器，这类照片可直接入库正常浏览（Windows 上报告的「缩略图生成失败」即此问题）
- 🩹 **失败可诊断** — 缩略图生成失败不再静默：失败原因会写入运行日志，个别文件再出问题可以按日志直接定位（格式/路径/解码器一目了然）

## 🛠 修复与体验优化

- **旅行页日期实时刷新** — 后台照片集合变化（移动/删除/外部增删引发的日期重算）即时反映到旅行页顶栏，且不打断正在编辑的表单
- 迁移照片进新旅行时，新旅行日期自动按首批照片填充，不再留空
- 「移出全部照片后旅行日期残留旧值」的问题随重算一并解决（自动值自动清空，手动值保留）
- 回收站恢复照片后，旅行日期自动回摆到包含该照片时的范围
