# 画廊 v0.11.0 · 地图、手账导出与照片级整理

> 把旅行照片，做成一本翻不腻的手账。本地优先 · 免安装即用 · 照片原地不动。

自 v0.9.0 以来的第一个新版本：旅行有了**地图**，一次旅行可以**排成一本纸感手账**导出带走，收藏与标签也细分到了**每一张照片**。

## ✨ 新亮点

- 🗺 **地图视图** — 有 GPS 的照片自动落点在地图上，点击拍立得标记直接定位到那张照片；没带位置的照片也有贴心引导（底图 © OpenStreetMap 贡献者）
- 📖 **导出手账** — 一键把旅行排成米白纸感的手账长卷：楷体标题、拍立得照片、缝线分隔。可导出 **PDF**（矢量，可送印）或**长图 PNG**（适合分享）
- ❤️ **照片级收藏与标签** — 收藏和小标签可以精确到每张照片；照片墙「只看收藏 / 按标签过滤」，⌘K 搜索也能命中照片标签
- 🍎 **HEIC / HEIF** — iPhone 原片直接导入浏览（缩略图与大图自动转码，拍摄时间与位置照常读取）
- 🗑 **删除旅行** — 时间线卡片与旅行页顶栏均可删除；一律移入系统废纸篓，可反悔

| 平台 | 文件 |
|---|---|
| macOS（Apple Silicon，macOS 14+） | `gallery-0.11.0-mac-arm64.dmg` |
| Windows 10/11（64 位） | `gallery-0.11.0-win-x64.exe` |

## 📝 全部变更（自 v0.9.0）

**整理与时间**
- 照片按 EXIF 真实拍摄时间排序；存量照片自动回填，开始日期为空的旅行可按照片自动推断
- 图注编辑：照片墙悬停按钮 / 灯箱内随时写

**灯箱重做**
- 滚轮 / 双击缩放（指针锚点）、拖拽平移、底部缩略图胶片条、信息栏（序号 / 文件名 / 摄于日期 / 尺寸）
- 灯箱内直接删除、设封面、收藏、写标签

**⌘K 搜索**
- 全局搜索旅行标题 / 描述 / 标签 / 图注 / 照片标签，按旅行聚合并标注命中字段、高亮命中词；空查询快速跳转

**地图与导出**
- 扫描与导入时读取 GPS 入库；地图视图支持亮暗主题、离线优雅降级
- 手账导出为纸制品配色，不随应用主题；超大旅行自动分段，封面缺失有占位

**体验与修复**
- 大相册（数百张）滚动流畅，照片墙按需渲染
- 拖照片进窗口即可选择放入哪次旅行；删除、导入等操作全部改为应用内确认与轻提示
- 数据库自动迁移（v1→v3），老数据无感升级
