# 画廊 v0.9.0 · 第一个公开预览版

> 把旅行照片，做成一本翻不腻的手账。本地优先 · 免安装即用 · 照片原地不动。

画廊是一款本地优先的旅行照片管理桌面应用：把你已有的照片文件夹变成一条按日期排开的手账时间线——拍立得照片堆叠、和纸胶带日期贴、缝线书脊。没有账号、没有云、没有追踪，照片永远在你自己的硬盘上。

## ✨ 亮点

- 📅 **手账时间线** — 旅行按日期倒序排开，封面照片以拍立得堆叠呈现，悬停即散开
- 🖼 **照片墙 + 灯箱** — 瀑布流缩略图秒开，灯箱看原图，←/→ 切换，视频直接拖进度条
- 🗂 **多相册** — 注册多个照片根目录随切随换；外置硬盘拔出灰显、插回即恢复
- 🏷 **标签 / 收藏 / 年份** — 三类筛选自由叠加，标签输入带常用联想
- 🌗 **三态主题** — 亮 / 暗 / 跟随系统，暗色是特调的暖褐「烛光」配色
- 🛡 **数据自持** — 照片原地不动，元数据只是一个本地 SQLite 文件，随时可以带走

## 📝 全部变更

Electron 重写后的首个公开版本（自 v0.8 的 Web 版完全重构）：

- electron-vite + React 18 + TypeScript 5 + Tailwind v4 全新桌面架构
- SQLite（better-sqlite3）本地元数据 + sharp 缩略图队列 + 自定义 `gallery-media://` 协议（支持视频 Range 请求）
- 相册目录扫描入库、watcher 实时同步、缺失相册检测与重定位
- 拖拽导入、旧版 `.settings.json` 数据一键迁移、废纸篓安全删除
- 手账风界面（语义化设计 token）、三态主题、标签输入联想、矢量图标体系
