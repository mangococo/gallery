# 画廊 v0.12.0 · 回收站、首页照片墙、翻阅室灯箱与五套主题

> 把旅行照片，做成一本翻不腻的手账。本地优先 · 免安装即用 · 照片原地不动。

这一版补上了照片管理最要紧的一块拼图：**删除从此可反悔**。旅行和照片先进回收站，随时恢复；配合重做的**灯箱翻阅室**、全新的**首页照片墙**和全套**右键菜单**，浏览、整理、反悔都顺手了。视觉上则完成了整套**语义主题系统**重构：五套主题各有完整明暗映射，还支持用自定义 CSS 随心换色。

## ✨ 新亮点

- 🗑 **回收站** — 删除旅行或照片不再直接进废纸篓：先软删除收进相册内的隐藏回收站（文件原地挪入 `.gallery-trash`，扫描与监听天然无视），随时**恢复**；「彻底删除」才送入系统废纸篓作为误操作的最后一道保险。外置盘没插时拒绝删除，绝不误伤
- 🏠 **首页照片墙** — 首页在「时间线 / 照片墙」间一键切换：全部旅行的照片与视频按拍摄时间从新到旧铺成瀑布流，万张级相册也能流畅滚动（增量渲染 + 惰性加载）
- 🔍 **灯箱「翻阅室」** — 暖褐深色房间 + 拍立得主舞台 + 楷体图注 + 底部胶片条。单击缩放、滚轮/双击缩放平移、`←→` 翻页、`Space` 播放、`I` 信息卡、`F` 全屏、`⌫` 删除；视频直接拖进度条
- 🎨 **五套主题** — 全新语义主题引擎：**暖纸**（米白暖棕）、**烛光**（蜜色琥珀暗房）、**月白**（素白青灰）、**黛蓝**（黛蓝靛青）、**青瓷**（青瓷釉色），每套都有完整的明暗两幅映射；亮 / 暗 / 跟随系统三态依旧，切换即时生效、重启保持
- 🖌 **自定义 CSS** — 设置里一键打开 `theme.css`，用语义 token 覆盖任意颜色（可按主题 × 明暗组合选择器），保存即热更新、无需重启
- 🖱 **桌面式右键菜单** — 照片、旅行、空白区、回收站全套右键菜单（支持键盘操作与子菜单）；照片墙多选后批量收藏 / 移动 / 删除
- 📦 **移动到旅行** — 照片与视频可在旅行之间搬家（文件随迁、封面自动交接、重名自动避让），也可在移动时顺手新建旅行
- ⭐ **封面即时生效** — 「设为封面」立即反映到时间线卡片：堆叠首图跟随封面（本次修复；此前封面只改徽标，主视图毫无变化）

## 🛠 修复与体验优化

- **可读性达标**：全应用颜色通过 WCAG 对比度契约（正文 ≥ 4.5:1、大字 ≥ 3:1，全部主题 × 明暗组合由测试自动校验）——主按钮改为主题色配对墨色，次要文字重定档，暗色下的低对比按钮一并修复
- **Esc 分层**：多层弹层叠放时 Esc 只作用于最上层——灯箱上取消删除确认不再连灯箱一起关掉，多选态上关菜单不再连带退出多选
- **时区修复**：拍摄时间与旅行日期统一按本地时区入库展示，东八区凌晨拍摄的照片不再「提前一天」
- **恢复旅行不再被改名**：从回收站恢复「日本之行」得到「日本之行 (2)」的bug已修复
- **批量删除/移动后灯箱跟随当前张**，不再跳到错误的照片
- **崩溃防护**：后台扫描/回填/缩略图任务全面兜底，外置盘拔出、监听异常等场景不再可能打断应用
- **侧栏相册操作**（重新定位被占用、扫描失败、重命名）失败给出明确提示
- macOS 关窗常驻 Dock（点图标重建窗口）；窗口位置记忆钳制屏内；日期时区、缩略图队列、文件监听等十余项稳定性加固

> **首次运行提示**：安装包未做代码签名——macOS 首次启动若提示无法验证开发者，到「系统设置 → 隐私与安全性」点击**「仍要打开」**，或执行 `xattr -cr /Applications/画廊.app`；Windows SmartScreen 弹窗点击「更多信息 → 仍要运行」。
